# Voice and Storytelling

## Voice levels

All levels share the same evidence ledger.

| Level | Use | Delivery |
|---|---|---|
| `清晰克制` | academic or formal briefings | few rhetorical devices; short examples; explicit evidence labels |
| `生动叙事` (default) | general courses and public talks | story-led explanations, questions, analogies, audible signposts, memorable closure |
| `观点强化` | user requests a stronger stance | sharper contrasts and more direct judgments, without changing evidence certainty |

Create an original voice. Reuse a source phrase only when it is useful and clearly attributed; do not clone a creator's distinctive verbal mannerisms.

## Story-guided explanation

Use a story as the entrance to a concept, not as decoration:

`人物或对象 → 情境 → 矛盾或触发 → 选择 → 连锁结果 → 概念揭示 → 主题回扣`

Start with a concrete scene and hold the explanation briefly. After the consequence chain, say what the story demonstrates. Prefer real stories already in the material. Label a new fictional story as `假设情境` or introduce it with “假如……”.

Do not force a story when the source is already concrete or when a fabricated scene would reduce accuracy. A short mechanism analogy is then enough.

## Classroom opening order

When a course presentation includes formal classroom duties, use this spoken order:

`问候与小组身份 → 与同学建立联系 → 感谢老师或场合 → 郑重承诺 → 反常识观察 → 中心问题 → 主题锚点 → 收获承诺`

Preserve any opening supplied by the user. The guarantee is the first rhetorical hook, not necessarily the first social sentence. If no identity or thanks is needed, begin directly with the guarantee.

## Opening contract

Default spoken structure:

1. `我保证，不是一个笑话。`
2. Name a surprising or uncomfortable observation.
3. Ask why it happens and why the listener should care.
4. State the theme anchor without fully explaining it.
5. Promise what the listener will be able to see, judge, explain, or do by the end.

The promise must be fulfilled in the close.

## Theme loop

Choose one stable keyword set. Return to it at least three times:

- **Opening:** an intriguing but incomplete claim.
- **Development:** after each major section, update the claim with the mechanism just learned.
- **Close:** elevate the claim from knowledge to a reusable way of seeing or acting.

Vary the sentence but preserve the anchor words. Each return must add meaning; verbatim repetition alone is not a loop.

## Audible language markers

Select markers by function and place them in speech notes.

| Function | Natural markers |
|---|---|
| focus | `先记住这句话` · `请注意这里的区别` |
| zoom | `把镜头拉近` · `我们再把视角拉远` |
| translation | `换句话说` · `翻译成人话就是` |
| turn | `真正的问题来了` · `但事情还没结束` |
| connection | `接下来，把这条线接上` · `这就解释了前面的现象` |
| return | `到这里，我们回头看` · `现在再看开头那句话` |
| distinction | `这不是……而是……` |

Do not stack markers in every paragraph. Use them where the listener needs orientation.

## Questions that advance reasoning

Across a full talk, use at least three relevant types:

- **代入：**“这件事与你有什么关系？”
- **预测：**“如果这个条件继续变化，下一步会发生什么？”
- **反事实：**“如果没有这个机制，结果会怎样？”
- **辨析：**“这是材料事实，还是讲者的进一步推演？”
- **回收：**“现在回到开头，你会怎样回答最初的问题？”

After a question, allow a pause or supply a transition into the answer. Every `内容提问` written in the slide specification must be spoken explicitly or with equivalent meaning in that page's speech notes. Across the whole talk, make at least three question types identifiable from the actual spoken script, not only from metadata or self-evaluation. Never ask several questions and abandon them.

## Analogy and plain-language translation

Keep the accurate term, then translate once. A useful analogy preserves relationships, not surface resemblance. Name the correspondence and return to the real concept:

```text
类比：政策工具箱。
对应关系：不同政策 = 不同工具；预期 = 工具尚未使用时的影响。
回到概念：这里讨论的是政策预期如何改变市场参与者行为。
```

If the analogy exaggerates, explicitly say where it stops applying.

## Compression without losing the talk

Treat `压缩` as meaning removal, not only word deletion. Protect the central question, theme anchor, argument chain, strongest story, audience questions, practical takeaway, and closing promise.

Compress in this order:

1. delete repeated explanations;
2. shorten transitions and examples;
3. replace long or abstract phrases with common words;
4. merge secondary evidence;
5. remove a core idea only when the target still cannot be met.

After compression, read the script as speech. Repair abrupt jumps, repeated sentence openings, and places where a question no longer receives an answer. Recalculate timing and synchronize all dependent files.

## Closing contract

Complete four emotional and intellectual moves:

```text
感谢你把这段并不轻松的内容听到这里。
为你愿意认真理解复杂问题的这份学习致敬。
希望今天提供的不只是几个结论，而是一张继续观察未来的地图。
期待你带着这套方法，获得更清楚的判断，也讲出属于自己的答案。
```

Rewrite the nouns and promised gain for the actual subject. Preserve the sequence `感谢 → 致敬 → 获得 → 期待`, and close the opening question.

## Common failures

| Failure | Correction |
|---|---|
| only labels what a slide covers | provide complete copy that can be pasted directly onto the slide: title, bullets, keywords, and diagram text |
| story is an entertaining detour | reveal the mechanism and return to the theme |
| speaker reads the slide | add scene, explanation, evidence boundary, question, and transition |
| repeated theme is a slogan | add a new layer of meaning at each return |
| rhetoric makes inference sound factual | announce `讲者认为`, `材料由此推演`, or `这一点仍待核实` |
| invented anecdote sounds real | label it `假设情境` |
| generic ending | name the actual gain and expected future use |
